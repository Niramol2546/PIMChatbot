# ไฟล์ตั้งต้น · ใช้คู่กับคู่มือ AiBA-W8-manual

ชุดนี้คือของที่ยังไม่ได้ตั้งค่า  ให้ทำตามคู่มือแล้วค่อย ๆ เติมเอง

---

## ไฟล์ในชุดนี้

```
index.html          หน้าเว็บตั้งต้น  ไว้ทดสอบ แล้วค่อยเอาหน้าจริงมาแทน
chat-widget.js      ตัว Chatbot ทั้งหมด  ไม่ต้องแก้
config.js           ไฟล์ตั้งค่า  ต้องแก้สามจุด
build-vectors.html  เครื่องมือสร้างไฟล์เวกเตอร์  ใช้ครั้งเดียว
worker.js           โค้ดสำหรับวางบน Cloudflare  ไม่ต้องอัปขึ้น GitHub
docs/               เอกสารตัวอย่าง 8 ไฟล์  เปลี่ยนเป็นของตัวเองได้
```

---

## สามจุดที่ต้องแก้ใน config.js

ค้นคำว่า **แก้ตรงนี้** ในไฟล์ จะเจอทั้งสามจุด

| บรรทัด | ใส่อะไร |
|---|---|
| WORKER_URL | ที่อยู่ Worker ของคุณ  ห้ามใส่ทับปิดท้าย |
| MODEL | ชื่อรุ่นจริงจากหน้า Models ของ OpenRouter |
| DOCS_BASE | ใส่ docs ถ้าเก็บในโฟลเดอร์  ใส่ค่าว่างถ้าอยู่ชั้นเดียวกัน |

---

## หนึ่งจุดที่ต้องแก้ใน worker.js

ค้นคำว่า `ALLOWED` แล้วแก้ให้เป็นโดเมน GitHub ของคุณ

```javascript
const ALLOWED = [
  "https://ชื่อผู้ใช้.github.io",
  "http://localhost:8000",
];
```

ถ้าไม่แก้ เว็บจะเรียก Worker ไม่ผ่าน และขึ้นว่าโดเมนไม่ได้รับอนุญาต

---

## ลำดับที่ควรทำ

1. ขอกุญแจ OpenRouter
2. สร้าง Cloudflare Worker  วางโค้ด  ใส่กุญแจเป็น Secret
3. สร้าง repo บน GitHub แบบ Public
4. อัปไฟล์ทุกไฟล์ ยกเว้น worker.js
5. แก้ config.js สามจุด  แล้วเปิด GitHub Pages
6. **ทดสอบด้วยโหมด local ก่อน** ว่าตอบคำถามได้
7. เปิด build-vectors.html สร้าง vectors.json  อัปขึ้น repo
8. เปลี่ยน SEARCH_MODE เป็น vector

รายละเอียดทุกขั้นอยู่ในคู่มือ **AiBA-W8-manual** ตอนที่ 4

---

## อย่าข้ามข้อ 6

ข้อ 6 คือการทดสอบด้วยโหมด local ก่อน ซึ่งยังไม่ต้องใช้ไฟล์เวกเตอร์

ทำแบบนี้เพื่อแยกปัญหา  ถ้าตอบได้แปลว่ากุญแจกับ Worker ใช้ได้แล้ว

ถ้าข้ามไปทำข้อ 7 เลยแล้วพัง จะไม่รู้ว่าพังเพราะอะไร

---

## ห้ามทำเด็ดขาด

**ห้ามใส่กุญแจลงในช่อง KEY ของ config.js**

ไฟล์นั้นเปิดอ่านได้โดยทุกคน และ OpenRouter จะเพิกถอนกุญแจอัตโนมัติภายในไม่กี่นาที

กุญแจต้องอยู่เป็น Secret บน Cloudflare เท่านั้น
